# Timer

A lightweight, always-on-screen timer for macOS. It works like a sticky note: a small window that shows a clock, timer, stopwatch or pomodoro at a glance.

> **A note on how it was built:** this app is fully vibe-coded. I built it with AI because I didn't have the patience to write it by hand. It's basic and rough around the edges, but it does the job for me, and I hope it does for you too.

## Motivation

Standard timer apps didn't fit how I work:

- **Not sticky-note-like.** I wanted a small, unobtrusive element on my screen that gives me the information I need without taking over.
- **Small gaps in functionality.** I wanted a stopwatch that records laps automatically at a time I set, and a simple watch that can be either analog or digital.

## Features

- **Clock:** analog or digital
- **Timer:** countdown
- **Stopwatch:** automatic lap recording at a set time
- **Pomodoro:** focus and break intervals

## Requirements

- macOS (other platforms are not supported)

## Installation

Download the app and install it on your Mac.

## Known limitations

This is a personal project. Expect rough edges and a limited feature set.
